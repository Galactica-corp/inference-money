# Assurance map

Each property that crosses a boundary (L1↔L2, contract↔SDK, SDK↔UI) and the tests that pin it on every layer. Integration and e2e specs carry the cell id in their title, so `grep -r "\[A3\]"` finds every test of a cell. Cell ids (`A…`) are unrelated to the plan's decision ids.

TS unit names are `<file>` `<test title>` in `packages/bridge-core/src/` unless marked showcase (`apps/showcase/`). Integration files are in `packages/integration/test/` (the clock specs, which move their own network's clock, in `packages/integration/clock/`), e2e specs in `apps/showcase/e2e/specs/`. Noir tests are TXE tests in `contracts/aztec/token_bridge/src/test/` unless marked token (`contracts/aztec/token/src/test/<file>.nr`) or keystone (`contracts/aztec/keystone`). Solidity names are in `contracts/evm/test/`. A `—` means the layer cannot observe the property; a blank means not yet covered.
